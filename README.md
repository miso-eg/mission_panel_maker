# Ver. 2.3.1：元のURLに共有機能を統合

公開URL: https://miso-eg.github.io/mission_panel_maker/

通常の画像作成とサポーターとの共有を同じ画面で利用できます。これまでの保存データをそのまま使えます。以前の共有版（/shared/）は元のURLへ移動し、招待リンクも保持します。以前の共有版に別の盤面がある場合は「保存・バックアップ」の「以前の共有版の盤面を引き継ぐ」で読み込めます（現在の盤面を置き換える確認があります）。

共有機能の初期運用上限は全体10ルーム・各5人・自動確認を含め1日10,000 APIリクエストです。日本時間9時に回数をリセットします。背景と元画像は端末に保持し、ギフト画像は縮小して共有します。

# MISSION PANEL MAKER

BINGOやギフト消費ミッションの盤面を編集し、行ごとのパネル数に合うサイズのPNGとして保存します。各行0〜12個、最大12行。0個の行は反映時に設定ごと削除して詰め、少ない行は中央寄せです。FREEは任意のパネルに指定できます。BINGOの判定・通知はありません。

## ローカル起動

このフォルダで `node server.cjs` を実行し、http://127.0.0.1:4173 を開いてください。Node.js以外のインストールは不要です。

初回はサンプル入りです。設定モードでパネルを選んで編集し、進行モードで使用数やミッション達成を更新します。パネル交換は設定モードで移動元の「別のパネルと交換」を押し、交換先を選びます。

画像・設定・進捗をIndexedDBで端末内に自動保存します。同じブラウザとURLで開いてください。ブラウザデータを削除すると消えるので、バックアップも保存してください。バックアップにはギフト画像も含まれます。

PNGには盤面のみが含まれます。コイン集計は各パネルの目標・使用済み・未達成分を合計します。超過使用数も使用済みに含め、他パネルの残りは減りません。

## GitHub Pages

index.html、style.css、app.jsを公開フォルダに置けば動きます。server.cjsはローカルプレビュー専用です。外部通信やログイン、外部ライブラリは使用しません。


## パネル開けモード

表示モードをパネル開けモードに切り替え、背景画像を選択します。達成パネルとFREEの範囲だけ背景を表示し、未達成・未設定・余白は隠します。背景画像のサイズを出力サイズにし、各行を画像の横幅いっぱいに等分します。背景のトリミングや引き伸ばしはしません。モードと背景は自動保存・バックアップ・PNGに対応します。背景は20MB以下、各辺8192px以下、合計1600万画素以下の入力画像を元サイズのPNGとして保存します。

画像選択後にトリミング画面を表示します。ドラッグ・拡大・位置スライダーに対応し、ギフトは正方形、背景は比率を選択できます。画像全体を使う操作とキャンセルも用意しています。
