# MISSION PANEL MAKER 共有版（Ver. 2.3.0）

公開URL: https://miso-eg.github.io/mission_panel_maker/shared/

既存の通常版とはブラウザの保存領域を分けています。通常版の盤面を使う場合は、通常版の「書き出す」でバックアップを保存し、この共有版の「読み込む」で復元してください。

設定を済ませて「共有開始」を押し、「共有の管理」でサポーターの名前を入力して招待リンクを発行します。共有中は設定を固定し、使用数と達成状態だけを更新できます。終了時は最新の盤面を端末に保存し、共有データを削除します。

ギフト画像は最大96pxに縮小して共有します。背景と元画像はライバーの端末だけに残します。共有画像の取得には招待リンクの権限が必要です。

初期運用は全体10ルーム、各ルーム5人まで。最終操作から7日で期限切れになります。既存サービスの無料枠を保護するため、共有機能全体は1日10,000 APIリクエストを上限とし、日本時間9時にリセットします。10秒ごとの自動確認もこの回数に含みます。上限時は共有更新を停止します。

通常版のURL・アプリファイル・保存データは変更していません。R2は使用しません。
